# 登录页与首页 UI 设计方案

> 适用范围：`workbase-admin-fornt` 登录页（`/login`）与登录后首页（`/workbase/`）。
> 设计方法：`ui-ux-pro-max` skill（表单 / 认证 / 图表 / 可访问性规则检索）。
> 高保真视觉稿见 [`login-home-ui-preview.html`](./design/login-home-ui-preview.html)。
> 与[富文本编辑器方案](./rich-text-editor-ui.md)共用同一套设计语言：Minimalism & Swiss Style + antd Token（`colorPrimary: #1677ff`、`borderRadius: 6`）。

## 1. 设计定位

| 维度     | 决策                                                       | 依据                                          |
| -------- | ---------------------------------------------------------- | --------------------------------------------- |
| 产品类型 | 生产力工具（企业后台）                                     | `ui-ux-pro-max` `product`：Productivity Tool  |
| 风格     | Minimalism & Swiss Style + 微交互                          | 与编辑器保持一致，几何、留白、高对比          |
| 页面模式 | 登录页：左品牌区 + 右表单区；首页：ProLayout 侧栏 + 内容区 | 后台惯例，ProLayout 为项目首选布局            |
| 图表     | 折线图（趋势）+ 统计卡（关键指标），ECharts                | `chart` 域：时间序列选折线；不足 4 点用统计卡 |
| 数字     | 千分位分隔、等宽数字（tabular-nums）、环比配箭头 + 文字    | Number Formatting 规则；不以颜色单独传意      |

## 2. 登录页

### 2.1 布局（≥1024px）

```text
┌──────────────────────────────┬──────────────────────────────┐
│  品牌区（约 45%，浅主色渐变） │      表单区（白底居中）        │
│                              │                              │
│  Logo + 产品名                │      欢迎回来（H1）            │
│  一句话价值说明               │      账号输入框                 │
│  2–3 条要点（图标 + 文字）    │      密码输入框（显隐切换）     │
│                              │      记住我 · 忘记密码          │
│  底部：版权信息               │      [登录]（全宽主按钮）       │
│                              │      底部：其他登录方式（可选） │
└──────────────────────────────┴──────────────────────────────┘
```

- 品牌区使用 `colorPrimary` 的低饱和渐变（如 #1677ff → #0F2B5A 方向）或纯色 + 细网格纹理，避免大面积高饱和。
- 表单列宽 360–400px，垂直居中；表单区留白 ≥ 48px。
- 单屏唯一主 CTA：**登录**（全宽、主色、36–40px 高）。

### 2.2 表单细节

| 元素     | 规格                                                                                               |
| -------- | -------------------------------------------------------------------------------------------------- |
| 标题     | 「欢迎回来」H1（24px / 600），下方辅助文案 `colorTextSecondary`                                    |
| 账号     | 常显 label（非 placeholder 代替）；`autocomplete="username"`；支持手机号/邮箱/工号                 |
| 密码     | 常显 label；显隐切换按钮（`aria-label="显示密码"`，状态可播报）；`autocomplete="current-password"` |
| 记住我   | Checkbox + 「忘记密码」右对齐链接                                                                  |
| 登录按钮 | 全宽主按钮；提交中 loading + 禁用（防重复提交）；请求 >1s 显示进度文案                             |
| 其他登录 | 次级分隔线「其他方式」+ 企业 SSO 图标按钮（可选，图标按钮必须带可见文字或 `aria-label`）           |

### 2.3 校验与错误（WCAG 2.2 重点）

- **就近内联错误**：错误文案在对应字段下方，`aria-describedby` 关联；红色描边 + 错误图标 + 文字（非仅颜色）。
- **表单级错误摘要**：登录失败（如密码错误）时在表单顶部出现错误摘要块，`role="alert"` 或聚焦到其标题（`tabindex="-1"`），逐条链接到出错字段；内联错误保留。
- **错误文案规范**：说明原因 + 恢复路径，如「账号或密码错误，请重新输入」，不写「Invalid input」。
- **不阻止粘贴**：禁止 `onpaste preventDefault`；允许密码管理器（`accessible-authentication` Critical 规则）。
- 校验时机：blur 后校验，提交时全量校验；不逐键报错。

### 2.4 响应式

| 断点       | 变化                                                                     |
| ---------- | ------------------------------------------------------------------------ |
| ≥1024px    | 左品牌区 + 右表单区                                                      |
| 768–1023px | 品牌区收窄或隐藏，表单居中，保留 Logo 头                                 |
| <768px     | 单列：顶部 Logo + 表单；触控目标 ≥44px；输入字号 16px（防 iOS 自动缩放） |

## 3. 首页（登录后）

### 3.1 页面骨架

```text
┌────────────────────────────────────────────────────────────────┐
│ ProLayout 侧栏        │  面包屑 · 搜索 · 通知铃 · 头像/下拉     │
│  Logo + 产品名        ├─────────────────────────────────────────┤
│  · 首页               │  PageContainer                         │
│  · 内容管理           │  ┌ 问候语（早上好，张明）+ 日期 ──────┐ │
│  · 用户管理           │  │ 快捷操作：新建文档 / 邀请成员 …     │ │
│  · 系统设置           │  └───────────────────────────────────┘ │
│                       │  ┌────┬────┬────┬────┐                 │
│                       │  │统计│统计 │统计 │统计│  4 张统计卡    │
│                       │  └────┴────┴────┴────┘                 │
│                       │  ┌─────────────────┬───────────────┐   │
│                       │  │ 趋势折线图        │ 待办 / 动态    │   │
│                       │  └─────────────────┴───────────────┘   │
└────────────────────────────────────────────────────────────────┘
```

- 布局优先 ProLayout + PageContainer（项目约定）；内容区背景 `colorBgLayout`，卡片 `colorBgContainer`。
- 首页定位为「工作台」：让人 5 秒内看懂概况、3 秒内找到入口，不堆砌全部数据。

### 3.2 顶部欢迎区

- 问候语按时间段（早上好 / 下午好 / 晚上好）+ 用户名；右侧显示日期（Day.js 本地化格式，如 `2026年11月18日 星期三`）。
- 快捷操作 2–4 个常用入口（主次分明：新建文档可为主按钮，其余为次级）。

### 3.3 统计卡（4 张）

| 元素   | 规格                                                                     |
| ------ | ------------------------------------------------------------------------ |
| 指标名 | 13–14px `colorTextSecondary`                                             |
| 数值   | 24px / 600，`tabular-nums`，千分位（如 `12,860`）；超大值缩写（`1.2万`） |
| 环比   | 箭头图标 + 百分比 +「较上周」文字；涨跌用图标形状 + 文字，非仅红绿色     |
| 卡片   | 无重阴影，1px `colorBorder` 或浅填充区分；hover 微抬起 ≤2px + 过渡 150ms |
| 可点   | 整卡可点（cursor-pointer、键盘可达、点击态反馈），跳转到对应列表         |

### 3.4 趋势折线图（ECharts）

- 时间序列 → **折线图**（`chart` 域结论）；系列 ≤ 2，填充透明度 20%；网格线浅灰。
- 必备：标题 + 图例（近 7 天 / 近 30 天切换 Segmented）+ 悬停 tooltip 显示精确值 + 轴标签带单位。
- 多系列时线型区分（实线/虚线）+ 直接系列标注，不靠色相单独区分。
- 无障碍兜底：提供数据表格（可折叠）或文字趋势摘要；键盘聚焦可读数值。
- 图表容器预留高度（防 CLS），加载时骨架图而非空白。

### 3.5 待办 / 动态列表

- 时间倒序；每行：状态图标 + 标题 + 相对时间（「2 小时前」，Day.js fromNow）。
- 超过 8 条显示「查看全部」；空状态给出引导操作（「暂无待办，去看看内容管理」）。
- 列表行 hover 浅填充；行内操作按钮 hover 才显现但键盘聚焦始终可见。

### 3.6 状态设计

| 状态     | 设计                                                             |
| -------- | ---------------------------------------------------------------- |
| 首次加载 | 统计卡 + 图表 + 列表骨架屏（`aria-busy="true"`），不用全屏转圈   |
| 空数据   | 卡片数值显示 `--` + 说明文案；图表区显示「暂无数据」+ 去创建引导 |
| 局部失败 | 仅失败卡片/模块显示错误占位 + 「重试」按钮，不拖垮整页           |
| 权限差异 | 无权限的快捷操作直接隐藏（不用禁用占位）                         |

## 4. Token 与实现映射

与编辑器方案共用 §10 Token 表（antd 6：`colorPrimary` / `colorBgLayout` / `colorFillSecondary` / `boxShadowSecondary` / `borderRadius: 6`），补充：

| UI 部件     | 建议实现                                                             |
| ----------- | -------------------------------------------------------------------- |
| 登录表单    | antd `Form` + `Input` + `Input.Password`（自带显隐切换）+ `Checkbox` |
| 错误摘要    | `Alert type="error"` 或自定义块，聚焦管理用 `ref.focus()`            |
| 页面壳      | `ProLayout` + `PageContainer`                                        |
| 统计卡      | `Card`/`Statistic`（自定义 tabular-nums 样式）+ `ArrowUpOutlined` 等 |
| 趋势图      | ECharts（项目约定），按需加载（不从入口统一导入）                    |
| 时间切换    | `Segmented`                                                          |
| 待办列表    | `List` / `ProList`，时间用 Day.js 相对时间                           |
| 通知 / 头像 | `Badge` + `Dropdown`（`Menu` 键盘行为现成）                          |
| 表单状态    | TanStack Query Mutation 管理登录请求；Zustand 存会话/用户态          |

## 5. 可访问性清单（登录 + 首页）

- [ ] 所有输入常显 `<label>`，`htmlFor` 关联；placeholder 不作为唯一标签。
- [ ] 错误就近内联 + `aria-describedby`；表单级错误摘要 `role="alert"` 且可聚焦。
- [ ] 密码显隐按钮有 `aria-label` 与状态反馈；不阻止粘贴、支持密码管理器。
- [ ] 登录按钮 loading 时禁用并保留可读文本；提交结果有明确反馈。
- [ ] 统计卡数值变化如需播报，用完整语句（「本月新增内容 328 篇」）。
- [ ] 图表不以颜色单独传意（线型 + 标注 + 数据表兜底）。
- [ ] 图表/卡片/列表键盘可达，焦点环 2px 可见；Tab 顺序与视觉一致。
- [ ] 头像下拉、通知面板支持 Esc 关闭并归还焦点。
- [ ] 相对时间提供精确时间（`title` 或 `aria-label`），日期使用本地化格式。
- [ ] 响应式断点 375 / 768 / 1024 / 1440 验证；移动端触控目标 ≥44px。
- [ ] 尊重 `prefers-reduced-motion`（卡片 hover 抬起等降级）。

## 6. 动效

- 登录成功：表单区淡出 + 跳转（≤250ms），不做大型过场。
- 统计卡 hover：`translateY(-2px)` + 边框加深，150ms；数字变化不做滚动计数动画（数据可信度优先）。
- 图表首次渲染做 200ms 淡入；切数据做过渡动画（ECharts 默认）。
- 全部动效仅 `transform` / `opacity`，遵守 `prefers-reduced-motion`。
